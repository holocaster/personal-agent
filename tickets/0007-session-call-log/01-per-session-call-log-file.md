# 01: One Call Log file per Session

**What to build:** Running the REPL twice leaves two Call Log files instead of one file that grew twice. Each Session mints a Session Id at start — a sortable UTC timestamp plus a short random suffix — and every line it writes goes to a file named after that Session Id under a new gitignored `logs/` directory. `ROUTER_LOG_PATH` keeps working as the override but now names the base path the Session Id is inserted into, not the literal file. Each Attempt line starts carrying its own `session_id` and a `type` discriminator so it stays meaningful when grepped out of its file.

The old single-file `router_log.jsonl` behavior goes away entirely, which breaks every place that assumed an exact filename. Migrating those call sites — `tests/conftest.py`'s `_isolate_router_log` fixture plus the exact-path setups and reads in `tests/test_call_log.py`, `tests/test_repl.py` and `tests/test_routing.py` — onto a shared path helper is part of this ticket, not a follow-up.

**Blocked by:** None (can start immediately).

**Spec:** `docs/specs/0007-session-call-log.md` (R01, R02, R03, R04 for the `attempt` type, R11, R12); **ADRs:** `docs/adrs/0003-call-log-per-session.md`.

- [x] A Session Id is a compact sortable UTC timestamp plus a separator plus a 6-character lowercase alphanumeric suffix (e.g. `20260922T142233Z-3f9a2c`), generated from the standard library only. It contains no colon, no path separator, and nothing else awkward in a filename or shell glob. Two Session Ids minted in order sort in that order lexicographically. Tests assert shape by pattern and ordering by minting two — no injected clock or random seam (Testing Decisions).
- [x] `run_repl` starts a Session through `call_log` before its first prompt, so the Session Id is minted once per Session rather than per Attempt. Two `run_repl` calls in one process produce two Session Ids and two distinct files; neither appends to the other's.
- [x] `ROUTER_LOG_PATH` keeps its name and its optional-override role, but means the base path. The default base path is `./logs/router_log.jsonl`. The resolved file inserts the Session Id before the final extension (`./logs/router_log-<session id>.jsonl`); a base path with no extension appends the Session Id instead. The parent directory is created on demand before the first write.
- [x] `call_log` exposes the path resolution as a public helper — the current Session Id, and the file path for the current or a given Session Id — and production code and tests both go through it. Only the test that specifically asserts the naming scheme may reconstruct or glob for a filename.
- [x] Appending an entry when no Session was started lazily mints a Session Id, so a direct `route` call with no REPL still produces a usable file (R03). `call_log` also exposes a reset for its in-process Session state.
- [x] Every `attempt` line carries `session_id` and `type: "attempt"` alongside the existing `timestamp`, `task`, `tier`, `provider`, `model`, `latency_ms`, `cost`, `prompt_tokens`, `completion_tokens`, `ok`, `error`, `attempt`, `cost_estimated`. All `attempt` lines share exactly one key set; `tests/test_call_log.py`'s exact `EXPECTED_KEYS` assertion is updated, not relaxed.
- [x] `tests/conftest.py`'s `_isolate_router_log` sets `ROUTER_LOG_PATH` to a base path inside `tmp_path` and resets `call_log`'s in-process Session state before each test, so no Session Id or running total leaks between tests. The exact-path setups and reads in `tests/test_call_log.py`, `tests/test_repl.py` and `tests/test_routing.py` resolve the real file through the helper. The full offline suite is green.
- [x] `.gitignore` ignores `logs/`; the obsolete `router_log.jsonl` entry is removed and the untracked repo-root `router_log.jsonl` deleted. No Call Log file is written into the repo root by a test run or a real Session.
- [x] The README's Call Log section and its `ROUTER_LOG_PATH` example describe the new default path, the base-path meaning, the per-Session file naming, and the `session_id`/`type` fields — concisely enough to write a `jq` filter from.
- [x] Nothing else moves: `route`'s public signature, the Classifier, the tier ladder, Escalation's technical-failure-only trigger (ADR-0001), retry counts and backoff, Attempt numbering within a tier, the Budget Guardrail, and the no-entry-for-an-interrupted-Attempt rule all behave exactly as before. Existing tests change only where they resolve the path or assert the key set.
