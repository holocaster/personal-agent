# 03: Compress preventively without losing pending Tool exchanges

**What to build:** An ordinary task automatically compresses eligible older context before an exchange crosses its route's budget pressure, then continues only that pending exchange. Recent complete turns and the in-progress task/Tool loop remain intact, including Gemini's original replay parts. If protected content cannot fit, the user receives a visible stop with executed Tool evidence preserved.

**Blocked by:** 02 — Make manual Compression bounded and transactional (`0037/02`).

**Spec:** `docs/specs/0037-context-window.md` (R4 replay measurement, R5, R6 automatic construction, R7, R9 pending-turn commit, R10 automatic notices, R11 exchange diagnostics/costs; Implementation Decisions: Exchange measurement and Provider Contract, Compression/replay/persistence; Testing Decisions). **ADRs:** ADR-0001, ADR-0002, ADR-0005.
