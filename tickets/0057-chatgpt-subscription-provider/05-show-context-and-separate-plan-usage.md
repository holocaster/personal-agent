# 05: Show current context and separate plan usage from API spend

**What to build:** The footer identifies the selected access method and honest current input occupancy, while `/usage` and `/report` preserve mixed-route API costs and observed plan consumption without invented currency/quota. This is a user-visible accounting checkpoint that can be verified independently once the task and durable evidence contracts exist.

**Blocked by:** 03 — Preserve ChatGPT continuity through Retry, Resume, Fork and Compression. Ticket 04 is not a blocker: use synthetic linked child evidence to test the same receipt contract, then retain full Subagent regression coverage when both are integrated.

**Spec:** [0057](../../docs/specs/0057-chatgpt-subscription-provider.md), D5 context formula/provenance, D7 token/cost normalization, D8/D9 attribution and D10; **ADRs:** [0015](../../docs/adrs/0015-chatgpt-subscription-provider.md), [0012](../../docs/adrs/0012-models-dev-selection-catalog.md).

**Areas:** REPL footer/config/usage, `InputBox` presentation, Router assessment surface/context budget, Run accounting, Session Report and bounded session/child evidence readers. Reuse existing compact terminal conventions and report group limits; no quota service/dashboard.

- [ ] Selected API routes show access method `API key`, input occupancy and current Run API spend with reported/estimated/unknown coverage. Selected ChatGPT shows `Assinatura ChatGPT`, occupancy and `/usage` without any monetary counter. Connecting while OpenAI remains selected does not relabel its footer. Missing/invalid/disconnected configuration shows unready/unknown, and exhaustion shows `Cota atingida` with guidance.
- [ ] Occupancy is the latest complete model-facing input estimate over effective input allowance from D5, including instructions, schemas, retained context/results, Summary/Memory/Todos/Skills and replay. It is not cumulative usage/total model window. Mark approximate counts and assumed/manual/public capacity provenance; unknown is not zero and opaque encrypted content does not get invented exact counts.
- [ ] Route/context changes, clear/Undo, Resume/Fork, Compression and relevant Tool/context updates invalidate or recompute stale assessment. Footer rendering cannot reuse the previous route's count/capacity as the newly selected route's occupancy. Test budgets, reserve/margin, absent capacity and output-reservation-estimate disclosure.
- [ ] `/usage` preserves current Run API costs from earlier routes and API children, separates reported/estimated/unknown coverage from plan input/output/cache/reasoning observations, and includes failed/Compression/child Attempts exactly once. Plan `cost=null` remains unavailable rather than `$0` or an API-equivalent price; no billing/quota/reset claims are inferred.
- [ ] `/report` retains bounded Session/Run/execution/purpose/route grouping and independent measurement coverage, distinguishes access methods/opaque registrations and preserves original API costs. Mixed known API subtotals are scoped as API costs rather than complete plan+API spend; correlated child evidence is not duplicated.
- [ ] `/usage` and `/config` expose `Manage usage: https://chatgpt.com/settings/usage`, safe account/readiness status and first-use-plan notice semantics. Plan exhaustion/ineligibility messages remain actionable without browser popups from inference, frozen API counters presented as plan cost, quota percentages or reset guesses.
- [ ] Integration tests cover API task → connect/picker cancel → ChatGPT task → failed plan task/Retry → API selection, retaining API spend and unknown plan cost through Resume/Fork and linked child evidence. Assert compact rendered footer/usage/report, independent missing/invalid measurement coverage and exact-once aggregates. Keep current API report/cache/accounting and prompt-surface tests green.
- [ ] Run focused input/REPL/context/usage/report/child accounting tests and the full `.venv/bin/pytest -q` suite. Update concise user-facing command/config documentation only for this feature's actual completed behavior; do not claim universal eligibility or successful live inference without an authorized real-account check.
