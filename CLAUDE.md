# personal-agent

A Python terminal LLM agent using an explicitly selected Provider/model pair for tasks and Compression.

## Where things live

- `.ai/PROJECT_STATE.md` — read before changing code for the current feature, active ticket and next action.
- `docs/CONTEXT.md` — consult for terminology and settled architectural decisions.
- `docs/briefs/`, `docs/specs/`, `tickets/` — per-feature plan and work breakdown, managed by the `sdd-main` skill.
- `docs/research/` — feature research and implementation status.

Follow the `sdd-main` workflow for feature work: discovery → spec → tickets → implement → review. Keep its artifacts in the paths above.
